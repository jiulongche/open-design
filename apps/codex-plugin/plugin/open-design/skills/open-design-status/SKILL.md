---
name: open-design-status
description: Verify which Open Design distribution and Codex plugin shell are active.
---

Use the `get_open_design_status` MCP tool when the user asks whether Open Design
is installed, which channel or version is active, or whether the local
development fixture matches the installed plugin.

Report the observed values. If the fixture is unreachable or the identity does
not match, explain the mismatch without changing Codex configuration,
reinstalling the plugin, or restarting the desktop app automatically.
